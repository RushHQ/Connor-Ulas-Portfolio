This project focuses on creating and maintaining a GitHub repository as a professional portfolio and version control system. The repository will host documentation, project files, and revision history, demonstrating technical skills and project management practices.

- Create a structured repository with README, documentation, and project files.

- Showcase work to peers, professors, and potential employers.

## ⚠️ Risk Assessment
**Identified Risks:**
- Difficulty learning Git commands.
- Repo not updated regularly.
- Accidental file deletion.

**Mitigation Strategies:**
- Use GitHub Desktop or VS Code extensions.
- Schedule weekly commits.
- Enable branch protection and backups.
